# Hi, I'm Tomislav (Tom) Protich 👋

**Founder of [Enterprise VPS Solutions](https://enterprisevpssolutions.com/). I build hosting automation, self-hosted AI, and the infrastructure that runs both.**

Most of what I make starts as "I wish this existed for my own servers" and ends up as a product, a pipeline, or a GPU running at 100% at 3 AM. I self-host nearly everything: my own GitLab, CI/CD runners, a multi-GPU AI cluster, monitoring, and a home media stack.

## 🛠️ What I build

**☁️ Hosting and cloud automation**
WHMCS modules that turn a hosting business into a machine: Proxmox VE/PBS provisioning, Cloudflare integration, IP address management, cPanel control, accounting and project-management bridges, fraud prevention, and a full client theme system.

**🧠 Self-hosted AI**
Multi-GPU inference on my own hardware (a 7x RTX 2080 Ti rig plus V100 nodes) running open models with Ollama, vLLM, LiteLLM, ComfyUI and Qdrant. I build agent orchestration, MCP servers, retrieval (RAG) pipelines, and a personal AI knowledge system that remembers everything I work on.

**🔐 Security and DevSecOps**
Security scanning built into every pipeline (Semgrep, Trivy, Gitleaks, ZAP, Checkov), managed security tooling for MSPs, and decentralized identity.

**🏢 Data center and GPU tooling**
DCIM and colocation sales software, plus GPU burn-in benchmarks with live power dashboards and cost-to-serve analysis.

**⚙️ Automation everywhere**
n8n and custom workflows, app-store publishing automation, and CI/CD pipelines that test, scan, encode, and release without anyone touching a button.
